# STB Everywhere - Backend

Backend service developed as part of a 2025 graduation project (PFE).

## Overview

STB Everywhere is a digital banking platform designed to provide secure and modern banking services.

This repository contains the backend application responsible for:

- Authentication & authorization
- User management
- Banking operations
- Transaction processing
- API services
- Security & access control

## Tech Stack

- ASP.NET Core
- MySQL, MongoDB
- JWT Authentication
- REST APIs
- Docker
- Api Gateway

## Project Context

This project was developed during a final-year engineering graduation project in 2025.

Repository published publicly in 2026 for portfolio purposes.
